# ShootSpot v1.5 — Development Plan

**Status:** v1.5 core shipped (build `1.5.0 (18)` on iOS, `385e4a3` on NAS); remaining polish items marked `[ ]` below.
**Goal:** Evolve ShootSpot from a V1 capture-and-discover MVP into a smarter, more complete **location scouting and location library** tool for photographers and videographers—without turning into a photo-sharing or social app.

## Guardrails & Constraints

1. **Stay in the location-scout lane:** Every feature must serve _finding, evaluating, and planning_ physical shoot locations. No photo editing, public comments, follower graphs, or social feeds.
2. **Preserve V1 privacy & anonymity (`D-06`, `D-08`):** Records remain anonymous by default; private projects and personal notes stay strictly private to their owner.
3. **Zero paid API keys:** Prefer on-device math (`suncalc`, `expo-location`, `react-native-svg`), existing PostGIS queries, OS-native intents (Calendar, Maps), and keyless/free open endpoints. Skip features that require paid per-request APIs (e.g., Google Directions/Places billing, paid weather/tide keys) until a paid tier or revenue justifies them.
4. **Ship incrementally:** Organized into 5 self-contained phases (`1.5A`–`1.5E`) so each can be built, tested on iOS/Android, and released independently.

## Phase 1.5A — Sun-Path & Light Intelligence (Zero External APIs)

Builds directly on `packages/shared/src/sun.ts` (`suncalc`), `bearingDeg`, `lat`/`lon`, and `focalLength35mm` already stored on every record.

### Scope

- [x] **Interactive Date & Time Scrubber (Location Detail):**
  - Allow picking any future shoot date and scrubbing time-of-day on `apps/mobile/src/app/records/[id].tsx`.
  - Compute and display sunrise, sunset, golden hour (AM/PM), blue hour (AM/PM), solar noon, and live `lightAngle` (`backlit`, `side_lit`, `front_lit`, `sun_down`) relative to the record's saved `bearingDeg`.
- [x] **"Next Best Light" & 24-Hour Light Bar:**
  - Visual 24-hour bar showing light periods and when the sun next aligns with the spot's facing direction (e.g., _"Next Golden Hour: Today 17:42–18:18 · Side-lit"_).
- [x] **Moon & Astro Planner:**
  - Use `suncalc` (`getMoonPosition`, `getMoonIllumination`, `getTimes` astronomical twilight) on `night` / `night_astro` records (or as an expandable astro row) to show moon phase, illumination %, moonrise/moonset, and dark-sky window.
- [x] **FOV Cone & Sun-Azimuth Vector on Maps:**
  - [x] Draw the camera's directional cone on the Location Detail mini-map (using `bearingDeg` and an approximate horizontal FOV derived from `focalLength35mm`), plus a sun-direction arrow for the selected date/time.
  - [x] Toggle on the main Map tab (`apps/mobile/src/app/(tabs)/map.tsx`) to show the current sun azimuth ray and next golden hour HUD.
  - [ ] Show directional bearing arrows on individual Map tab pins (`MapPin` currently has no `bearingDeg`).

### Technical Notes

- **Shared (`@shootspot/shared`):** Extend `sun.ts` with `daylightSummary(date, lat, lon, bearingDeg?)`, `moonSummary(date, lat, lon)`, and `horizontalFovDeg(focalLength35mm)`.
- **Backend:** None required—100% deterministic client/shared computation.
- **UI:** `react-native-svg` for the 24h light bar and compass/sun arc; `react-native-maps` `Polygon`/`Polyline` for the FOV cone.

## Phase 1.5B — Advanced Scouting Filters & Location Freshness

Unlocks the rich production metadata already captured in `advancedInputSchema` (`packages/shared/src/scout.ts`) and keeps the library trustworthy over time.

### Scope

- [x] **Advanced Scout Filters (Feed & Map):**
  - Extend `feedQuerySchema`, `mapQuerySchema`, and `apps/mobile/src/app/filters.tsx` with optional production filters:
    - **Drone:** `allowed` only
    - **Permits:** `permitRequired = no`
    - **Practical:** `parking = yes`, `power = yes`, `restrooms = yes`
    - **Access:** `terrain = easy` (or max walk-in time)
    - **Conditions:** `tideDependent = yes`
    - **Focal Range:** Wide (`< 28mm`), Standard (`28–70mm`), Telephoto (`> 70mm`)
- [x] **Location Freshness / "Still Accurate" Verification:**
  - Lightweight anonymous community verification on Location Detail: _"Still accurate"_ (updates a `last_verified_at` timestamp) or _"Flag changed"_ (e.g., scaffolding, locked gate, seasonal change, construction).
  - Show a subtle freshness indicator on Location Detail (e.g., _"Verified 3 weeks ago"_ or _"Flagged: construction reported"_).
- [x] **"Other Angles at This Spot" Grouping:**
  - On Location Detail, query published records within ~25–30 m (PostGIS `ST_DWithin`) and show them in a compact _"Other angles at this spot"_ strip above _"Nearby locations"_ so multi-angle scouts of one venue stay connected without cluttering the main feed.

### Technical Notes

- **API (`services/api`):** Add filter predicates to `feed.ts` and `/v1/map` (indexed JSONB / generated columns if needed for query speed), add `POST /v1/records/:id/verify` (rate-limited, 1 vote per user per record per 30 days), and return `lastVerifiedAt` / `changeFlag` in `PublicRecord`.
- **Database:** New migration for `location_verifications` table and cached `last_verified_at` on `locations`.

## Phase 1.5C — Free-Tier Environmental Context & Field Integrations

Brings live shoot-day awareness and OS-native workflow handoffs with **zero paid API keys**.

### Scope

- [x] **Shoot-Day Weather & Wind Forecast (Open-Meteo):**
  - [x] Integrate [Open-Meteo](https://open-meteo.com/) (free, no API key required for non-commercial/prototype use; review commercial terms before launching a paid tier).
  - [x] On Location Detail, show a compact 7-day forecast for the pin's `lat`/`lon`: temperature, cloud cover %, precipitation probability, and wind speed & gusts.
  - [ ] Show shoot-date weather inside Project Schedule view and include visibility in forecast data.
- [x] **Calendar Shoot-Window Export:**
  - [x] One-tap **"Add to Calendar"** on a Location Detail's Light Planner window (exports `.ics` on iOS / share sheet on Android with location label, coordinates, `bearingDeg`, and light window).
  - [ ] Include a `shootspot://records/<id>` deep link in the exported calendar event description.
- [x] **Multi-App Navigation & Airspace Handoff:**
  - [x] Expand **"Open in Maps"** into an action sheet: Apple Maps, Google Maps, Waze, plus **Check Drone Airspace** (`OpenAIP`) when `drone !== 'no_fly'`.
  - [ ] Add a one-tap **Copy Coordinates** (`lat, lon`) action to the navigation sheet.

### Technical Notes

- **API / Caching:** Proxy or cache Open-Meteo responses by rounded grid (~1–2 km) with a 1–3 hour TTL in the API (or in-memory/Postgres cache) to stay well within fair-use limits and keep mobile requests fast.
- **Mobile:** `expo-calendar` (check Expo SDK 58 compatibility and permission flow in context).

## Phase 1.5D — Smart Projects (Shoot-Day Planner)

Transforms private Projects (`apps/mobile/src/app/projects/[id].tsx`) from a simple bookmark list into an actionable shoot-day planner, laying the foundation for future `D-11` paid features.

### Scope

- [x] **Project Map View:**
  - Toggle between **Board**, **Schedule**, and **Map** inside a Project: see all saved locations on one map with numbered pins (`1, 2, 3…`), straight-line distances between consecutive stops, and arrow reordering (zero paid routing APIs).
- [x] **Target Shoot Date & Light Schedule:**
  - Assign an optional **Shoot Date** to a Project.
  - Automatically compute each saved spot's Golden Hour / Blue Hour / Best Light window for that date (via `suncalc`) and offer a **"Sort by Best Light"** view to sequence a shoot day from sunrise to blue hour.
- [x] **Private Per-Spot Project Notes:**
  - Allow adding a short private note to any saved record inside a Project (e.g., _"Park at north gate, bring 1.2m scrim, talent arrives 17:00"_), visible only to the project owner.

### Technical Notes

- **Database & API:** Add `shoot_date` (nullable `date`) to `projects` and `note` (nullable `text`, max 300 chars) + `sort_order` (`int`) to `project_items`.
- **Shared:** Update project DTOs in `packages/shared/src/api.ts`.

## Phase 1.5E — Live Scout Compass (Viewfinder Sun-Path Tool)

A focused field tool for scouts standing on location who want to verify where the sun will be at a future hour or season.

### Scope

- [x] **Scout Compass / Sun-Path Overlay:**
  - [x] Accessible from the Camera screen as an opt-in toggle (`D-22`) using `expo-location` heading + `suncalc` + `react-native-svg` to render the current sun position, today's sun-path arc, sunrise/sunset azimuth markers, and golden hour indicator.
  - [x] Launch Scout Compass directly from Location Detail (_"Preview Sun Here"_), add a future-date selector inside the overlay, and surface live heading calibration accuracy (`backlog 3.7 / 5.13`).

### Technical Notes

- **Mobile:** Validate heading accuracy (`backlog 3.7 / 5.13`) on iOS and Android devices during this phase so the compass arc aligns reliably with the physical horizon.

---

## Suggested Implementation Order

1. **Phase 1.5A** (Sun-Path & Light Intelligence) — highest photographer/videographer value, zero backend/API risk.
2. **Phase 1.5B** (Advanced Filters & Freshness) — makes the growing location library far more useful.
3. **Phase 1.5D** (Smart Projects) — turns saved spots into shoot plans.
4. **Phase 1.5C** (Weather & Calendar Integrations) — adds live shoot-day intelligence on free tiers.
5. **Phase 1.5E** (Live Scout Compass) — hardware/sensor-heavy polish once device heading calibration is verified.
